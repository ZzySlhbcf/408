数据链路层之所以要将比特组合以帧为单位传输, 是为了出错时只重发出错的帧

# 3.2.1 字符计数法

帧的首部使用一个计数字段来记录该帧所含的字节数

若计数字段出错, 即失去帧边界划分的依据, 则接收方就无法判断所传输帧的结束位和下一帧的开始位, 收发双方将失去同步

# 3.2.2 字节填充法

使用特定字节来界定一帧的开始与结束, SOH表示帧的开始, EOT表示帧的结束
为了使信息位中出现的特殊字符不被误判位帧的首位定界符, 在特殊字符前填充一个转义字符ESC来加以区分, 以实现数据的透明传输

# 3.2.3 零比特填充法

使用以一个特定的比特流01111110来标志一个帧的开始与结束
发送方扫描整个数据字段, 若出现5个连续的1, 自动在其后面加一个0, 防止出现6个连续的1
接收方则逆操作, 每收到5个连续的1, 若其后为0, 则删除这个0恢复原始数据

在数据链路层早期使用的HDLC协议中, 使用这种比特填充的首位标志法来实现透明传输

# 3.2.4 违规编码法

在物理层进行比特编码时, 常采用违规编码法, 将比特1编码成"低-高"电平, 比特0编码成"高-低"电平, 而"高-高"电平和"低-低"是违规的, 可以借用违规编码序列来定界帧的起始和终止, 在IEEE802标准采用了这种编码方式

违规编码不采用任何填充计数便能实现数据的透明传输, 只适合采用冗余编码的特殊编码环境
