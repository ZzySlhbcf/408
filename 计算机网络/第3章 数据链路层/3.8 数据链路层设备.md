# 3.8.2 以太网交换机

## 交换机的原理和特点

以太网交换机也称二层交换机, 它实际上是一个多端口的网桥叫, 通常具有十几个或更多的端口

1. 交换机的每个端口可以直接与主机或其他交换机相连, 且每一个端口和连接到端口的主机构成了一个碰撞域, N个端口的以太网交换机就用N个碰撞域
2. 以太网交换机的端口还有存储器, 能在输出端口繁忙时把到来的帧进行缓存
3. 以太网交换机具有并行性, 即能同时连通多对端口, 使多对主机能同时通信. 全双工模式下, 每一对相互通信的计算机都像独占传输媒体那样, 无碰撞地传输数据


以太网交换机可以分为直通式和存储转发方式两类，一般为存储转发方式
1. 直通方式: 只检查帧的目的MAC地址(6B), 以决定该帧的转发接口
   直通方式的优点是交换时延非常小, 缺点是它对传送帧不提供差错检测, 它也不能将具有不同速率的输入、输出端口直接接通
2. 存储转发方式: 先将接收到的帧缓存到高速缓存器中, 并检查数据是否正确, 确认无误后根据查找表将该帧从相应端口发送出去; 若发现帧有错, 则将其丢弃
   优点是可靠性高, 且能支持不同速率接口间的转换, 缺点是时延较大

>[!info] 现代存储转发式交换机可以支持不同速度的输入、输出端口间的转换, 保持高速端口与低速端口间的协同工作

## 交换机的自学习功能

交换机的自学习功能可被概括为逆向学习源地址, 即当交换机从某个端口收到源地址为X的数据帧时, 它能学习到: 通过这个端口可以把目的地址为X的数据帧交付给目的主机. 以太网交换机的这种自学习功能使得它能够即插即用, 不必人工进行配置

以太网交换机有4个端口, 分别连接主机A、B、C、D。交换机的交换表由两个项目组成, 目的MAC地址和转发端口. 一开始, 交换表是空的 
假定A先向B发送一帧, 从端口1进入交换机. 由于交换表中没有B的地址, 交换机会向除端口1以外的所有端口广播这个帧, 同时把此帧的源地址A和端口1成对地写入交换表, 保证B能收到这个帧. C和D在收到帧后, 因目的地址不匹配将丢弃此帧, 该过程也称为过滤
接下来假定B通过端口3向A发送一帧, 交换机根据交换表中的匹配表项将该帧从端口1转发给A, 同时把此帧的源地址B和端口3成对地写入交换表
之后, 只要C和D也向其他主机发送帧, 交换机就会把C和D及对应的端口号成对地写入交换表

>[!info] 交换机所连的主机会随时变化m 因此需要定期更新交换表中的表项
>为此, 交换表中的每个表项都设有一定的有效时间, 过期表项将被自动删除

## 共享式以太网和交换式以太网的对比

|          | 共享式以太网(集线器)  | 交换式以太网(交换机)                |
| -------- | ------------ | -------------------------- |
| 主机发送普通帧  | 集线器将帧转发到所有端口 | 根据帧的目的MAC和自身的交换表明确的转发给目的主机 |
| 主机发送广播帧  | 集线器将帧转发到所有接口 | 交换机从其他所有接口转发该帧             |
| 多对主机同时通信 | 产生冲突         | 实现多对接口的高速并行交换              |
