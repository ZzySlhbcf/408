+ 点对点信道: 一对一的通信方式, PPP是目前使用最广泛的点对点协议
+ 广播信道: 采用共享广播信道的有线局域网普遍使用CSM/CD协议, 而无线网则使用CSMA/CA协议

# 3.1.1 数据链路层所处的地位

1. 链路: 从一个节点到**相邻节点**的一段物理链路
2. 数据链路: 除了链路本身, 还需要一些必要的通信协议来控制这些数据的传输, 把实现这些协议的硬件和软件加到链路就构成数据链路
3. 帧: 链路层对等实体之间进行逻辑通信的协议数据单元

# 3.1.2 链路管理

数据链路层的建立维持和释放过程称为链路管理
# 3.1.3 封装成帧和透明传输

>[!info] 透明
>某个实际存在的事物看起来不存在

> 封装成帧: 在一段数据的前后分别添加首部和尾部, 构成帧
> 为了提高帧的传输效率, 帧的数据长度尽可能大于首部和尾部的长度, 帧长增加, 发生差错重传的代价也越大

[[3.2 组帧]]

>透明传输: 不论什么样的比特组合的数据, 都能按照原样无差错地在这个链路上传输

# 3.1.5 差错控制

1. 位错: 帧中某些位出现差错, 通常采用循环冗余检验CRC来发现位错
2. 帧错: 帧丢失、帧重复或帧失序

OSI: 必须让数据链路层向上提供可靠传输, 在CRC的基础上增加了帧编号、确认和重传机制

对于通信质量良好的有线链路, 数据链路层已不再使用确认重传机制, 仅进行CRC检错, 对出错的帧的重传任务由高层西医(传输层的TCP)完成
