# 2.1.1 基本概念

## 信源、信道和信宿

信道上传输的信号分为有基带信号和宽带信号
+ 基带信号: 未经调制的原始信号, 直接传输基带信号时, 称为基带传输
+ 宽带信号: 将基带信号进行调制

+ 单工通信
+ 半双工通信: 可发送或接收消息, 但不能同时
+ 全双工通信

# 2.1.2 信道的极限容量

## 奈奎斯特定理 (奈式准则)

极限码元传输速率为2W波特, W是信道的频率带宽(单位为Hz), V为码元的离散电频数量, 极限数据传输速率为
$$理想低通信道的极限数据传输速率=2W\log_{2}V\quad(b/s)$$
1. 码元的传输速率是有上限的, 若超出上限, 会出现严重的码间串扰问题
2. 信道的带宽越大, 传输码元的能力越强
3. 并未限制信息传输速率, 即未对每个码元最多可以携带多少比特的信息

## 香农定理

$$信道的极限数据传输速率=W\log_{2}(1+S/N)\quad(b/s)$$
其中, W为信道的频率带宽, S为传输信号的平均速率, N为信道内的高斯噪声功率, S/N为信噪比
+ 无单位记法: 信噪比=S/N
+ 分贝记法: 信噪比=$10\log_{10}(S/N)\quad(dB)$

>[!attention] 使用香农定理计算极限数据传输速率, 信噪比采用无单位记法

1. 信道的带宽或信噪比越大, 极限传输速率越高
2. 对一定带宽和信噪比, 信息传输速率的上限是确定的
3. 只要信息传输速率低于极限传输速率, 就能找到办法无差错传输

# 2.1.3 编码与调制

## 数字数据编码为数字信号

![[数字数据编码.png]]

1. 归零RZ: 高电平为1, 低电平为0, 每个码元中间均跳变为0
2. 非归零NRZ: 不用跳变
3. 反向非归零NRZI: 电平跳变表示0, 不跳变表示1
4. 曼彻斯特编码: 每个码元中间发生跳变, 向下跳变表示1, 向上跳变表示0 ^8fcb79
5. 差分曼彻斯特: 每个码元中间发生跳变, 码元开始处不变表示1, 跳变表示0

## 模拟数据编码为数字信号

1. 采样: 周期性扫描, **采样频率必须大于等于模拟信号最大频率的两倍**
2. 量化: 按照分级标准转换对应数值并取整
3. 编码: 量化得到的离散整数转换为二进制编码

## 数字数据调制为模拟信号

![[Pasted image 20251021000528.png]]

1. 振幅AM或幅移键控ASK: 改变载波的振幅表示1和0, 抗干扰能力差
2. 调频FM或频移键控FSK: 改变载波的频率表示1和0, 抗干扰能力强
3. 调相PM或相移键控PSK: 改变载波的相位
4. 正交幅度调制QAM: 设波特率为B, 采用m个相位, 每个相位有n种振幅
   $$R=B\log_{2}(mn)$$
