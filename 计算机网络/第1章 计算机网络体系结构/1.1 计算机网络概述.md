# 1.1.2 计算机网络组成

1. 组成部分
   硬件: 主机、通信链路 (双绞线)、交换设备 (路由器交换机)和通信处理器 (网卡)
   软件: 实现各种资源的软件
   协议: 规定了网络传输数据所遵循的规范
2. 工作方式
   边缘部分: 供用户直接使用的主机
   核心部分: 大量网络和连接这些网络的路由器组成, 为边缘部分提供连通性和交换服务
3. 功能组成
   通信子网: **传输介质、通信设备和相应的网络协议**, **具有数据传输、交换、控制和存储的能力**
   资源子网: 实现资源共享功能的设备及其软件的集合

# 1.1.3 计算机网络的功能

数据通信、资源共享、分布式处理、提高可靠性、负载均衡

# 1.1.4 电路交换、报文交换与分组交换

连续传送大量数据, 传送时间远大于建立时间, 采用电路交换
提高网络信道的利用率, 报文交换和分组交换更优, 分组交换比报文交换时延小, 也更为灵活, 适合突发式数据传送

![[三种交换方式的比较.png]]

## 电路交换

在进行数据传输前两个用户建立专用的物理通信路径, (由通信双方之间的交换设备和链路逐段连接), 在数据传输过程中, 该路径始终被用户占用, 直到通信结束之后

| 优点    | 缺点       |
| ----- | -------- |
| 通信时延小 | 建立连接时间长  |
| 有序传输  | 线路利用率低   |
| 没有冲突  | 灵活性差     |
| 实时性强  | 难以实现差错控制 |

## 报文交换

用户数据加上源地址、目的地址等信息后, 封装成报文
采用存储转发技术, 整个报文先传送到相邻的结点, 全部存储后查找转发表, 转发到下一结点
**每个报文都可单独选择到达目的端的路径**

| 优点      | 缺点     |
| ------- | ------ |
| 无建立连接时延 | 转发时延高  |
| 灵活分配线路  | 缓存开销大  |
| 线路利用率高  | 错误处理低效 |
| 支持差错控制  |        |

>[!note] 报文大小没有限制, 交换节点要有较大的缓存空间

## 分组交换

也采用存储转发技术, 在源主机发送之前, 先把较长的报文划分为若干个较小的等长数据段, 在每个数据段前面添加一些由必要控制信息组成的**首部**, 构成分组 (Packet)

| 优点             | 缺点                                                        |
| -------------- | --------------------------------------------------------- |
| 方便存储管理         | 存在存储转发时延                                                  |
| **流水线方式**传输效率高 | 需要传输额外的信息量                                                |
| 减小了出错概率和重传代价   | 分组交换网采用数据报服务时, 可能出现失序、丢失或重复分组的情况<br>虚电路服务由呼叫建立、数据传输和虚电路释放 |

# 1.1.6 计算机网络的性能指标

1. 速率
2. 带宽: 网络的通信线路所能传送数据的能力, 所能传送的"**最高**数据传输速率"
3. 吞吐量: **单位时间**某个网络的实际数据量
4. 时延: 发送时延+传播时延+处理时延+排队时延
   + 发送时延(节点将分组推向网络的时间): 也称传输时延=分组长度/发送速率
   + 传播时延(一个比特从一个节点到另一个节点的时间): 信道长度/电磁波在信道上的传播速率
   + 处理时延: 在交换节点为存储转发而进行的一些必要时间
   + 排队时延: 在输入队列和输出队列中排队的等待所花的时间
1. 时延带宽积: =传播时延\*信道带宽
   发送端发送第一个比特即将到达终点时, 发送端已经发出了多少比特
2. 往返时延(RTT): 发送端发出一个短分组, 到发送端收到来自接收端的确认总经历的时间
   包含处理时延、排队时延、转发数据时的发送时延
3. 信道利用率: 有数据通过的时间/总时间
   + 太低会浪费网络资源
   + 太高会产生较大的时延, 导致网络瘫痪
