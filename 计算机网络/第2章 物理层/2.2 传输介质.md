# 2.2.1 双绞线、同轴电缆、光纤与无线传输介质

## 双绞线

把两根互相绝缘的铜导线并排放在一起, 然后用规则的方法绞合起来. 绞合可减少对相邻
导线的电磁干扰

1. 非屏蔽双绞线UTP: 五屏蔽层双绞线
2. 屏蔽双绞线STP: 为了提高双绞线抗电磁干扰的能力, 可以在双绞线的外面再加上
一层用金属丝编织成的屏蔽层形成屏蔽双绞线

优点: 价格便宜, 通信距离短
缺点: 长距离的模拟传输需要放大器放大衰减信号, 对于数字传输, 要用中继器将失真的
信号整形

## 同轴电缆

同轴电缆常由内导体、绝缘层、外屏蔽层以及外部保护层组成
1. 基带同轴电缆(50$\Omega$): 主要用于传输基带数字信号, 在早期局域网中应用广泛
2. 宽带同轴电缆(75$\Omega$): 主要用于传送宽带信号, 在有线电视系统中应用广泛

优点：由于外导体屏蔽层的作用, 同轴电缆具有**很好的抗干扰特性**, 被广泛用于传输较高
速率的数据
缺点: 其传输距离比双绞线更远, 价格一般也更高

## 光纤

光纤通信就是利用光导纤维(以下简称光纤)传递光脉冲来通信; 有光脉冲表示1, 无光
脉冲表示0
1. 多模光纤: 允许多条光路径同时传输, 光源为发光二极管, 适用于短距离通信
2. 单模光纤: 单模光纤适合长距离传输并且衰减更小, 但单模光纤的制造成本以及对光源的要求比多模光纤高
   **单模光纤的光源为定向性很好的激光, 而不能使用较便宜的发光二极管**

特点: 
1. 传输损耗小, 中继距离长, 对远距离传输特别经济
2. 抗雷电和电磁干扰性能好
3. 无串音干扰, 保密性好, 不易被窃听或截取数据
4. 体积小, 重量轻
## 无线传输介质

### 无线电
在自由空间传播的射频频段的电磁波

1. 可沿地球表面以地波形式传播, 主要应用于通信领域如手机通信、无线局域网等
2. 主要以天波的形式靠大气层中的电离层反射传播, 可用于国际广播、远距离无线电通信
等
### 微波
在对流层的视距范围内, 以频率为300MHz~300GHz的电磁波进行信息传输
微波通信主要适用于视距内的直线传播, 即接收天线与发送天线需要保持互相可见, 微波通信主要有地面微波接力和卫星通信这两种方式
+ 微波接力: 为实现远距离通信, 必须在一条微波通信信道的两个终端之间建立若干个中继站从而构成一个微波中继系统, 中继站把前一站送来的信号经过放大后再发送到下一站
+ 卫星通信: 利用人造地球卫星作为中继站来转发电磁波, 实现两个或多个地球站之间的通
信

优点: 通信容量大、距离远、覆盖广
缺点: 保密性差、端到端传播时延长

### 红外通信与激光通信
红外通信和激光通信将要传输的信号分别转换为红外光信号和激光信号, 再直接在空间中传播. 红外通信广泛应用于家电遥控器、手机、笔记本电脑等短距离通信场景
红外通信属于点对点无线传输, 传输距离短, 传输速率也很低, 并且中间不能有障碍物

# 2.2.2 物理层的接口特性

1. 机械特性: 定义物理连接的特性, 规定物理连接时所采用的规格、接口形状、引线数目、引
脚数量和排列情况等
2. 电气特性: 规定传输比特流时, 线路上信号的电压范围, 阻抗匹配、传输速率和距离限制等
3. 功能特性: 指明某条线上出现的某一电平的电的意义以及每条线的功能, 如数据线、控制线。
4. 过程特性: 也称规程特性，指明对于不同功能的各种可能事件的出现顺序
