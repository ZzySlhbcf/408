# 6.1.1 客户/服务器模型

在客户/服务器（C/S）模型中, 存在着特定的客户端和服务器, 提出请求的视为客户端, 接收请求的视为服务器端(总是打开的主机称为服务器)

1. 服务器在指定端口监听客户端的连接请求
2. 客户端作为服务发起方主动向服务器指定端口发出连接请求
3. 服务器收到来自客户端的连接请求后会先进行一系列准备工作如身份验证、资源分配等,  之后再与客户端建立连接
4. 连接建立后, 服务器与客户端进行双向通信, 如服务器可以查找客户端所请求的数据, 并将数据返回给客户端
5. 通信结束, 双方断开连接

>[!attention] 在C/S模型中, 客户之间不能直接通信, 需要服务器进行中转

优点: 安全, 因为服务器始终管理着访问控制权限, 同时服务器也更容易备份
缺点: 是这类网络不可靠, 因为服务器的故障会影响到所有客户端, 同时CS网络的建立和维护成本也更高

1. 网络中各计算机的地位不平等, 服务器可通过对用户权限的限制来达到管理客户机的目的
2. 客户机相互之间不直接通信
3. 可扩展性不佳
# 6.1.2 P2P模型

在对等(P2P)模型中, 每个节点既可以是客户端也可以是服务器, 它既可以请求服务也可以提供服务. 处于P2P网络中的一台设备也被称作一个对等节点
P2P是建立在客户/服务器模型的基础上的,, 它把单个服务器的负担分摊给了若干个客户节点

优点: 
1. 它更容易维护, 无须专门派人维护网络
2. 在向多用户分发一个文件时, P2P模型可以将任务分配给多个节点, 用户可请求最近的、速率快的节点服务器, 所以通常比C/S模型所需的时间更短
3. 减轻了服务器的计算压力, 消除了对某个服务器的完全依赖, 可以将任务分配到各个节点上, 因此大大提高了系统效率的资源利用
4. 多个客户机可直接共享文档
5. 可扩展性好
4. 网络健壮性强
缺点: 
1. P2P网络并不是很安全
2. 在获取服务的同时, 还要给其他节点提供服务, 因此会占用较多的内存, 影响整机速度
