# 3.6.1 局域网的基本概念和体系结构

1. 为一个单位所拥有, 且地理范围和站点数量均有限
2. 所有站点共享较高的总带宽(较高的数据传输速率)
3. 较低的时延和较低的误码率
4. 各站为平等关系而非主从关系
5. 能进行广播和多播

决定局域网特性的三要素

| 网络拓扑            | 传输介质 | 介质访问控制方法                 |
| --------------- | ---- | ------------------------ |
| 星形结构            | 双绞线  | CSMA/CD协议或令牌总线协议(总线型局域网) |
| 环形结构            | 同轴电缆 | 令牌环协议(环型局域网)             |
| 总线型结构           | 光纤   |                          |
| 星型和总线型结合的复合拓扑结构 |      |                          |

>[!info] IEEE802委员会
>是专门指定局域网和城域网标准的机构, 为不同规格的局域网制定了一系列标准

| 标准编号       | 名称                | 逻辑拓扑 | 物理拓扑    | 介质访问控制协议  |
| ---------- | ----------------- | ---- | ------- | --------- |
| IEEE802.3  | 以太网               | 总线型  | 星型/拓展星型 | CSMA/CD协议 |
| IEEE802.4  | 令牌总线网             | 环型   | 总线型     | 令牌总线协议    |
| IEEE802.5  | 令牌环网              | 环型   | 星型      | 令牌环协议     |
| IEEE802.8  | FDDI<br>光纤分布式数据接口 | 环型   | 双环型     | 定时令牌协议    |
| IEEE802.11 | 无线局域网             | 星型   | 星型      | CSMA/CA协议 |
IEEE802将局域网的**数据链路层**分为**介质访问控制MAC**和**逻辑链路控制LLC**:
+ 与接入到传输媒介相关的内容都放在MAC子层, 向上层屏蔽物理层的差异
  MAC子层的主要功能: 媒体访问、帧格式化、物理寻址、比特差错控制、链路层管理
+ LLC子层与传输媒体介质无关, 为网络层提供统一的逻辑视图
  它的主要功能: 给帧加序号、帧差错控制、给网络层提供接口、建立与释放逻辑连接

# 3.6.2 以太网与IEEE802.3

>[!info] 以太网采用两项措施来简化通信
>1. 采用无连接的工作方式, 即不对方送的数据帧编号, 又不要求接收方发送确认, 即以太网**尽最大努力交付, 提供不可靠服务, 对差错控制则由高层完成**
>2. 发送的数据使用**曼彻斯特编码**的信号

>[!info] 标准名称解释
>+ 10指标准速率为10Mb/s
>+ Base指基带以太网
>+ 5和2指单段最大传输距离不超过500m或185m
>+ T指双绞线, F指光纤

>[!info] 网卡/通信适配卡(NIC)
>网卡是一种硬件设备, 用于实现主机与局域网内其他主机的通信
>网卡实现了数据链路层和物理层的功能, 针对数据链路层, 它的主要功能有: 数据串行传输和并行传输的转换、数据缓存、帧的封装与拆封、介质访问控制
>网卡在物理层的功能主要有定义数据发送与接收所需的时钟基准、数据编码格式、电路标准、线路状态

## 以太网的MAC地址

这个地址被固化在网卡的[[3.2 主存储器#3.2.2 只读存储器|ROM]]中, 所以被称作为硬件地址, 又称为物理地址或MAC地址

物理地址长度为6字节, 常用十六进制表示, 其中高24位为厂商代码, 低24位位厂商自行指派的网卡序列号
>MAC地址是网络上各接口的唯一标识, 一台设备如果安装有多张网卡, 他就有多个MAC地址; 路由器若同时连接两个网络上, 它需要两个适配器和两个MAC地址


+ 单播MAC地址: 第一个字节最低位为0的MAC地址, 如80-80-90-36-25-D4, 用于一对一通信
+ 组播MAC地址: 第一个字节最低位为1的MAC地址, 如81-80-90-36-25-D4, 用于一对多通信
+ 广播MAC地址: 所有位全为1的MAC地址, 即FF-FF-FF-FF-FF-FF, 用于一对全体通信

## 以太网的MAC帧

以太网帧格式有两种标准, 一种是DIX Ethernet V2标准, 另一种是IEEE802.3标准, 这里仅介绍常用的以太网V2的MAC帧格式

![[以太网V2标准的MAC帧格式.png]]

8字节前导码分为两个字段: 第一个字段是7字节的前同步码, 用来实现MAC帧的比特同步; 第二个字段是1字节的帧开始定界符(10101011), 表示后面的信息就是MAC帧

>[!attention] 以太网不需要帧结束定界符
>以太网传送帧时, 各帧之间必有间隙, 接收方只要找到帧的开始定界符, 后面连续的比特流都属于该帧
>以太网采用[[3.2 组帧#3.2.4 违规编码法|违规编码]]思想, 因为以太网使用[[2.1 通信基础#^8fcb79|曼彻斯特]]编码, 每个码元必有一次电压的跳变, 如果发送方网络接口上的电压不再变化(11或者00), 接收方就能找到帧的结束位置, 这个位置往前数4个字节就是[[3.3 差错控制#^62f6aa|FCS]]字段

+ 目的地址: 6字节, 帧在局域网上的目的适配器的MAC地址
+ 源地址: 6字节, 传输帧到局域网上的源适配器的MAC地址
+ 类型: 2字节, 之处数据字段中的数据应交给哪个上层协议处理, 如网络层IP
  值位0x0800表示IPv4、0x86DD表示IPv6、值为0x0806表示ARP
+ 数据: 46~1500字节, 以太网最大传输单元式1500字节, 若IP数据报大于1500字节, 则必须分片
  以太网帧必须满足最小长度64字节, 当IP数据报少于46字节, MAC子层就在数据字段的后面加一个整数字段的填充字节的填充字段
+ 检验码FCS: 4字节, 检验范围从目的地址段到数据字段, 采用32位CRC码

### 无效MAC帧

1. 帧的长度不是整数个字节
2. 用收到的帧检验系列FCS查出有差错
3. 数据字段的长度不在46~1500字节之间

用于检查出的无效MAC帧就简单地丢弃, 以太网不负责重传丢弃地帧

## 高速以太网

| 标准名称   | 100Base-T以太网  | 吉比特以太网        | 10吉比特以太网 |
| ------ | ------------- | ------------- | -------- |
| 传输速率   | 100Mb/s       | 1Gb/s         | 10Gb/s   |
| 传输介质   | 双绞线           | 双绞线或光纤        | 双绞线或光纤   |
| 通信方式   | 半双工或全双工       | 半双工或全双工       | 全双工      |
| 介质访问协议 | 半双工下使用CSMA/CD | 半双工下使用CSMA/CD | 无        |

### 100Base-T以太网

又称快速以太网, 在双绞线上传输100Mb/s基带信号地星形拓扑以太网
100BASE使用MAC帧格式和传统以太网一致, 最短帧长仍为64字节

### 吉比特以太网

又称千兆以太网, 它使用双绞线或光纤作为传输介质, 帧格式与传统以太网一致
吉比特以太网允许在1Gb/s下以全双工和半双工两种通信模式工作
吉比特以太网在半双工模式下使用CSMA/CD协议, 并增加了载波延伸和分组突发

+ 载波延伸: 保持MAC帧最短帧长位64B, 将争用期长度提高到512B
+ 分组突发: 当很多短帧需要发送时, 只有第一帧使用载波延伸地方法填充, 之后地短帧在等待一个必要地帧间最小间隔后就可以直接发送

### 10吉比特以太网

10吉比特以太网的帧格式与传统以太网一致, 并保留了802.3标准规定的以太网最小帧长和最大帧长
10吉比特以太网只工作在全双工模式下, 它不存在争用问题, 也不使用CSMA/CD协议

# 3.6.3 IEEE802.11无线局域网

无线局域网按照是否有固定基础设施主要分为IEEE802.11无线局域网和自组网络(ad hoc network)两类
+ 自组网络没有AP, 各节点地位平等, 中间节点都为转发节点, 因此都具有路由器功能

## 无线局域网的组成

IEEE802.11标准规定无线局域网的最小构件式基本服务集BSS

1. 一个BSS包含一个接入点AP和若干个移动站
2. 无线局域网中所有移动站, 无论是在同一个BSS内还是在不同BSS间, 都必须通过接入点AP通信
3. 一个BSS覆盖的地理范围叫做一个基本服务区BSA, 通常BSA的直径不超过100米
4. 为了识别不同的BSS, 每一个BSS会被赋予以一个BSSID, 通常BSSID被设置为该BSS的AP的MAC地
   分配系统DS将多个BSS相互连接, 构成一个扩展的服务集

## 802.11局域网和MAC帧

802.11帧共有数据帧、控制帧和管理帧三种类型

![[802.11局域网的数据帧的格式.png]]

802.11数据帧由以下三部分组成:
1. MAC首部: 共30字节
2. 帧主体: 帧的数据部分, 不超过2312字节
3. 帧检测序列FCS: 帧的尾部, 长度为4字节

>[!attention] 在CSMA/CA协议中介绍过允许发送数据的站点对信道预约一段时间, 并将这个这个时间写入持续期字段

802.11数据帧有四个地址字段, 这几个地址的含义与帧控制字段中的"去往AP"(移动站发送到接入点)和"来自AP"(从接入点发往移动站)这两个子字段的数值有关
+ 地址1永远是接收地址, 即直接接收数据帧的节点地址
+ 地址2永远是发送地址, 即实际发送数据帧的节点地址
+ 地址3和地址4山取决于数据帧中的"来自AP"和"去往AP"这两个字段的数值

>[!info] 在有基础设施的网络中一般只使用前三种地址, 很少使用仅在自组移动网络中使用的地址4

| 去往AP | 来自AP | 地址1                | 地址2                | 地址3  | 地址4 |
| ---- | ---- | ------------------ | ------------------ | ---- | --- |
| 0    | 1    | 接收地址=目的地址          | 发送地址=AP地址<br>BSSIS | 源地址  | -   |
| 1    | 0    | 接收地址=AP地址<br>BSSID | 发送地址=源地址           | 目的地址 | -   |

# 3.6.4 VLAN基本概念与基本原理

当一个以太网中包含的计算机太多时:
1. 以太网中出现大量广播帧, 特别是经常使用的ARP和DHCP
2. 一个单位的不同部门共享一个局域网, 对信息保密和安全不利

虚拟局域网(VLAN)是由一些局域网网段构成的与物理位置无关的逻辑组, 这些网段具有某些共同的需求. 具体来说, 是在交换式局域网的基础上, 采用网络管理软件, 将处于不同地理位置的网络用户加入同一个逻辑子网(即VLAN)中, 构成一个逻辑上的广播域
一个VLAN内部的广播和单播流量都不会转发到其他VLAN中, 从而有助于控制流量、减少设备投资、简化网络管理、提高网络的安全性
>[!attention] 虚拟局域网只是局域网给用户提供的一种服务, 而并不是一种新型局域网

![[三个虚拟局域网.png]]

## 虚拟局域网的实现方法/划分方式

1. 基于端口的VLAN: 利用以太网交换机的端口来划分广播域, 如一个交换机的1、2号端口被设置为VLAN1, 3、4号端口被设置为VLAN2
2. 基于MAC地址的VLAN: 分别配置每个MAC地址对应的虚拟局域网来划分VLAN。
3. 基于网络层的VLAN: 利用每个主机的网络层地址或协议类型(如果支持多协议)进行VLAN划分

## 扩展的以太网MAC帧

为了支持虚拟局域网, IEEE802.3ac标准定义了扩展的以太网帧格式, 在原来的以太网帧首部插入了一个4字节的VLAN标记字段, 插入VLAN标记的帧称为802.1Q帧
VLAN标记字段的组成:
1. IEEE802.1Q标记类型: VLAN标记的前两个字节, 总是设置为Ox8100
2. VLAN标识符(VID): VLAN标记后两个字节山的最后12位, 指明该帧属于哪一个VLAN
 
>[!note] 802.1Q帧只在跨交换机的干线链路上使用，在交换机和主机之间使用的仍然是标准以太网帧
