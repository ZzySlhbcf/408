# 2.3.1 中继器

1. 中继器的功能: 对信号再生和还原以消除传输过程中产生的失真和衰减, 进而增加信号传输的距离和延长
网络的长度
2. 中继器的两端: 端口仅作用于信号的电气部分, 并不管数据中有没有错误数据或者不适于网段的数据
   中继器工作在物理层, 不具备存储转发功能, 所以它连接的两部分必须**具有相同的速率和物理层协议**, **但传输介质可以不同**
3. 5-4-3规则: 即一个网段最多划分为5个子网段, 最多使用4个中继器, 最多只有3个子网段连接计算机终端

>[!attention] 放大器和中继器都起放大作用
>1. 放大器放大的是**模拟信号**, 其原理是**放大衰减的信号**
>2. 中继器放大的是**数字信号**, 其原理是**整形再生衰减的信号**

# 2.3.2 集线器(Hub)

本质是一个多端口的中继器, 当Hub工作时, 一个端口接收到数据信号后会对该信号进行**整形放大**, 使之再生(恢复)到发送时的状态, 紧接着转发到其他所有(除输入端口外)处于工作状态的端口

集线器连接的多台设备所构成的网络在物理上是**星形网络**, 但在**逻辑上是总线形网络**, 所有连接的设备共享同一通信介质和物理带宽
